# Assessment Submission Guidelines

## Instructions

1. **Create a Branch**  
   Create a new branch in this repository using your full name in the format `lastname-firstname` (e.g., `doe-john`).  

2. **Submit Your Work**  
   Add all your code, data files, and answers to this branch. Since this is a small task, a single commit is sufficient.  

3. **Push and Notify**  
   Push your branch to the repository and notify us once your submission is complete.  

Good luck!
